## ⚠️ Sempre rastreie o trabalho como issues (skill `track-work`)

Toda feature, correção, melhoria ou débito técnico DEVE virar uma issue no
projeto "Refrigeração Garrido Website" (`cmtstixt000o5s501zmcy0rvp`) no WB
Project Manager, agrupada no milestone da fase, com o status em dia
(Backlog/Todo → In Progress → Done). Antes de planejar ou iniciar trabalho
não-trivial, e sempre que descobrir um bug/melhoria, invoque a skill
**`track-work`** (`.claude/skills/track-work/SKILL.md`) — ela tem o projectId, os
status IDs, a localização da API key e o CLI `pm.sh`.
